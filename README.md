# ORBIT Terminal

### One terminal. Multiple shells. One seamless experience.

**ORBIT Terminal** is a modern, lightweight desktop terminal application designed to bring different command-line environments together in one clean, unified interface.

Built with **Tauri 2, Rust, JavaScript, and xterm.js**, ORBIT aims to make working with command-line tools simpler, faster, and more accessible.

Whether you're working with PowerShell, Command Prompt, or Git Bash, ORBIT gives you one place to launch and manage your terminal sessions.

---

## ✨ Features

- **Multiple Shell Support** — Launch Windows PowerShell, Command Prompt, and Git Bash.
- **Modern Interface** — A clean, dark, industrial-inspired interface with a distinctive ORBIT design.
- **Lightweight Desktop Application** — Powered by Tauri and Rust.
- **Terminal Sessions** — Start and stop terminal sessions through the application.
- **Shell Selection** — Choose your preferred command-line environment.
- **Simple Navigation** — Return to the shell selection screen and launch another environment.
- **Developer Focused** — Designed with simplicity, productivity, and extensibility in mind.

## 🚀 Getting Started — Developers

Want to explore the source code or build ORBIT Terminal yourself?

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- [Rust](https://www.rust-lang.org/tools/install)
- [Git](https://git-scm.com/)
- [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/)

### Clone the repository

```bash
git clone https://github.com/OtakuSamaRS/ORBIT-Terminal-Development.git
cd ORBIT-Terminal-Development
```


The compiled application will be generated inside the Tauri build output directory.
